## Cross-cutting themes (appear in ≥2 reviews)

1. **Activation / cold-start.** #1, #9 — new recruiters get `credits: 0` and are blocked before
   first value. Fix: trial credits + sandbox candidate.
2. **Correctness bugs surfaced under review.** #1 — `CandidateDetailPage.tsx` `WLEIS < 20`
   threshold flags top-scoring candidates; `checkAbandonedSessions` never refunds
   `status == "Invited"` links and mis-derives `sessionId`.
3. **Trust & compliance posture.** #4, #5 — unauthenticated candidate DSAR endpoints,
   BOLA/IDOR, invalid "mandatory consent", US-region functions vs EU market.
4. **Marketing positioning discipline.** #4, #8 — **never** label preSift "AI"; use
   "validated psychometric testing / IRT-3PL". Any "AI" claim flips it into EU AI Act
   Annex III (4)(a) high-risk territory.
5. **Measurement & distribution missing.** #7, #11 — no SEO surface, no tracking pixels:
   organic and paid both start from zero.
6. **ATS/pipeline integration gap.** #6, #1 — no bulk CSV export or ATS data contract.
