# Agency Agents Roster

The Agency Agents persona suite provides specialized domain expert personas imported into `.agents/rules/`. All persona rule files specify `trigger: manual` so they never auto-load into context simultaneously, conserving token budgets and preventing rate limit (HTTP 429) errors.

## Activation Instructions

To activate an agent persona, read ONLY its specific rule file:
- Load `.agents/rules/<slug>.md` for the designated role.
- Never concatenate or bulk-load the catalog into the active prompt context.
